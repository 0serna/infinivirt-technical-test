# Agent List Scope is Assignee or creator

The assignment lets an Agent consult tickets but not “all” tickets. List Scope for an Agent is Tickets where they are Assignee or `created_by`; unassigned Tickets created by someone else stay out. Assignee-only would hide Tickets they just registered before a Supervisor assigns them. A shared unassigned queue (or the global list) would collapse the Agent/Supervisor distinction. List Scope is consult, not a table filter. A later single-Ticket read uses the same set and does not confirm that a Ticket outside it exists. Consult is not the Operational Dashboard. That view still counts only Open Tickets assigned to the Agent.
