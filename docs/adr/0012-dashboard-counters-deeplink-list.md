# Dashboard counters deep-link to Ticket List filters

Operational Dashboard KPI counters navigate to the Ticket List with the matching filter(s) in the URL (Open / In progress / Open Ticket load / Stale / Agent assigned-open). We extend the Ticket List (and list API) to honor those filters (including multi-Status Open load and Stale) rather than building a second filtered queue only on the dashboard. Short dashboard tables still link to individual Ticket consult.
